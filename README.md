# 🔒 Proxy Switcher

Бесплатное open-source Windows-приложение на Python для направления интернет-трафика **конкретного приложения (.exe)** через SOCKS5 или HTTP прокси. Аналог Proxifier.

---

## 📋 Возможности

- ✅ Поддержка **SOCKS5** и **HTTP/HTTPS** прокси с авторизацией (логин/пароль)
- ✅ Выбор **конкретного .exe** — только его трафик идёт через прокси
- ✅ **Ротация прокси** — автоматическая смена по таймеру или вручную
- ✅ **Проверка прокси** — тест доступности перед использованием
- ✅ **Список прокси** — несколько серверов, переключение между ними
- ✅ **Логирование** — журнал событий и статус подключения в реальном времени
- ✅ **Тёмная тема** интерфейса

---

## 🖥️ Системные требования

## ⚙️ Установка

### Способ 1: Автоматически (рекомендуется)

## 📖 Использование

### Шаг 1: Добавление прокси

1. Нажмите кнопку **"➕ Добавить"**
2. В диалоге заполните:
   - **Тип прокси**: SOCKS5 или HTTP
   - **IP / Хост**: адрес прокси-сервера (например `194.28.208.236`)
   - **Порт**: порт прокси (например `9106`)
   - **Логин / Пароль**: если требует авторизация
3. Нажмите **"🔍 Проверить"** — приложение проверит доступность прокси
4. Нажмите **"💾 Сохранить"**

### Шаг 2: Выбор приложения

1. Нажмите **"📂 Выбрать .exe"**
2. В файловом диалоге найдите нужный `.exe` файл
3. Название выбранного файла отобразится в правой панели

### Шаг 3: Запуск

1. Выберите прокси в списке (кликните на строку)
2. Нажмите **"▶ Запустить"**
3. Приложение запустится с настроенным прокси
4. В журнале событий отобразится статус подключения

### Шаг 4: Остановка

- Нажмите **"⏹ Остановить"** для завершения проксирования

## 🔄 Ротация прокси

Автоматическая смена прокси по таймеру:

1. Добавьте **несколько прокси** в список
2. В секции **"Ротация прокси"** включите чекбокс **"Авто-ротация"**
3. Укажите интервал в секундах (например `60`)
4. При запуске приложения ротация начнётся автоматически

Также можно нажать **"⏭ Следующий прокси"** для ручного переключения.

---

## 🔍 Проверка прокси

- **Проверить** — проверяет выбранный в списке прокси
- **Проверить все** — проверяет все прокси в списке одновременно

Результат проверки отображается в столбце **"Статус"**:
- 🟢 `✅ ОК (150 мс)` — прокси работает
- 🔴 `❌ Превышено время ожидания` — прокси недоступен

## ⚙️ Как работает перехват трафика

Приложение запускает целевой `.exe` с переменными окружения:
- `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` — устанавливаются на ваш прокси

Это работает для большинства приложений, которые уважают системные настройки прокси:
- ✅ Браузеры (Chrome, Firefox, Edge — при запуске из командной строки)
- ✅ Приложения на Python (requests, urllib)
- ✅ curl, wget, git
- ✅ Многие игровые лаунчеры

> ⚠️ Некоторые приложения игнорируют переменные окружения прокси и требуют системного перехвата трафика (через WinDivert/Proxifier). Для таких случаев рекомендуется использовать Proxifier.

## ❓ FAQ

**Q: Почему трафик приложения не идёт через прокси?**
A: Некоторые приложения не используют системные переменные окружения для прокси. Попробуйте Proxifier для полного перехвата трафика.

**Q: Прокси показывает ❌ — что делать?**
A: Проверьте IP, порт и данные авторизации. Попробуйте другой прокси-сервер.

**Q: Поддерживается ли HTTPS прокси?**
A: Да, при выборе типа HTTP приложение поддерживает также HTTPS прокси.

**Q: Где хранятся настройки?**
A: В файле `config/settings.json` рядом с приложением.

**Q: Можно ли добавить несколько прокси?**
A: Да, нажмите "➕ Добавить" несколько раз и используйте ротацию для автоматического переключения.
